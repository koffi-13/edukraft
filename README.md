# EduKraft PWA

Application mobile de formation professionnelle hébergée sur GitHub Pages.

## 🌐 URL PWA Builder

Utilisez cette URL dans PWA Builder:
```
https://[votre-username].github.io/edukraft-pwa/
```

## 📱 Fonctionnalités

- Formation professionnelle complète
- Modules interactifs
- Badges et progression
- Mode hors-ligne
- Interface moderne

## 🚀 Déploiement

1. Créez un repository "edukraft-pwa" sur GitHub
2. Activez GitHub Pages dans les settings
3. Copiez ces fichiers dans le repository
4. L'URL sera disponible en quelques minutes
